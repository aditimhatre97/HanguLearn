# 💜 HanguLearn — Korean Learning Companion 🇰🇷

**HanguLearn** is a beginner-friendly Korean language learning web application built with Python and Streamlit. It helps learners explore Hangul, practise Korean vocabulary, and test their knowledge through interactive quizzes.

The project combines my interest in Korean language learning with my passion for software development and Artificial Intelligence & Machine Learning.

## ✨ Features

- **📚 Hangul Learning:** Explore Korean vowels and consonants.
- **🗂️ Vocabulary Flashcards:** Practise Korean vocabulary through flashcards.
- **🎯 Interactive Quizzes:** Test your understanding of Korean.
- **💜 Lavender-Themed Interface:** Enjoy a clean, beginner-friendly learning experience.
- **📈 Basic Progress Feedback:** Track learning activity during your app session.

## 🛠️ Tech Stack

- **Language:** Python
- **Framework:** Streamlit
- **Version Control:** Git and GitHub

## 🚀 Getting Started

Follow these steps to run HanguLearn locally.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/HanguLearn.git
cd HanguLearn
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Create a virtual environment

On Windows:

```powershell
py -m venv .venv
```

### 3. Install dependencies

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. Run the application

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Streamlit will provide a local URL that you can open in your browser.
