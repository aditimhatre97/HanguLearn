 HanguLearn 🇰🇷💜

HanguLearn is a simple Korean language learning app I built using Python and Streamlit. The idea behind this project comes from my own interest in learning Korean, and I wanted to create something that makes practising the basics a little more interactive and fun.

 Features
- Learn Korean vowels and consonants (Hangul)
- Practise vocabulary using flashcards
- Test your knowledge with interactive quizzes
- Explore a simple, lavender-themed interface

 Built With
- Python
- Streamlit

 Run Locally
Clone the repository, install the dependencies, and start the app:

```bash
git clone https://github.com/aditimhatre97/HanguLearn.git
cd HanguLearn
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Replace `aditimhatre97` with your GitHub username.
